# Acceptance Criteria (Expanded)

CA1: Onboarding completes within 5 minutes; data saved to user profile.
CA2: Initial plan generated by IA with goals, training, and diet aligned to objective.
CA3: Training log and meal log accepted; calories/macros calculated per objective.
CA4: Progress visuals saved and plotted weekly (weight, measurements, PRs).
CA5: Weekly IA-driven adjustments with explicit rules (deficit, macro tweak, deload).
CA6: Configurable notifications; automatic sending per rules.
CA7: Guardrails prevent extreme plans; respect medical constraints.
CA8: Data security: safe data model and access controls.
CA9: MVP includes Onboarding, Home Today, Training, Nutrition, Progress, Settings screens.
