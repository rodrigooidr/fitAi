# Ambiguities and Answers (for MVP scope)

1. Ambiguity: onboarding data scope (which fields mandatory vs optional) -> Answer: make age, height, weight mandatory; objective, level optional with defaults.
2. Ambiguity: logging format for workouts (units, reps, sets) -> Answer: standardize unitless counts, weight in kg, save rest in seconds.
3. Ambiguity: IA rules length and guardrails -> Answer: implement simple rules; avoid extreme deficits (>25% TDEE) and no drug/substance guidance.
4. Ambiguity: notification preferences -> Answer: default notifications for workouts, meals, and weekly check-ins, with user-configurable settings.
