# Frontend - fitAi App

## Tecnologia
**React Native (Expo)** para desenvolvimento cross-platform (iOS/Android)

## Principais Funcionalidades
- Onboarding inteligente (questionário de saúde/fitness)
- Tela "Hoje" com plano diário (dieta + treino)
- Tela de Treino com vídeos de execução
- Tela de Nutrição com macros e substituições
- Progresso com gráficos e comparador de fotos
- Configurações e perfil do usuário
